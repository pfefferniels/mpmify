Honest caveats

  • Why this record. This is the same Vienna window demo-0 headlined, kept although the model loses to the constant-tempo null on it by a factor 9.7 — swapping in a window the model wins would misrepresent the sim2real gap, which is the point of showing a real performance at all.
  • Timing is worse than the null here. The predicted maps render onsets at 1331 ms RMSE; one constant tempo fitted to the same window gets 137 ms — a factor 9.7 against the model. The tempo map is carrying a shape the performance does not have.
  • Velocity RMSE 16.47 against the null's 16.60 (-1%).
  • The articulation head over-fires on real playing: 135 of 177 notes (76%). It was trained on canonical synthetic data where ~15% of onset dates carry an articulation (CANONICAL A1); a human deviates everywhere, so every note looks articulated. Thresholding and era priors are the v1.0 answer.
  • No ground truth exists for this record. Nothing on this page is a curve-space or instruction-space score — there is no reference MPM to compare instructions against. Every number is render-space: the prediction rendered and measured against the performance.
  • The pedal-state MAE on this page is a leaked number. Input feature 14 is the sustain state at the note's onset — sustain_state_lookup(rec['sustain_cc']) evaluated at ms_on − asynchrony offset — and the pedal head's own label is that same call at that same instant (dataset.piece_to_features_v4 vs piece_to_note_labels_v4). The head can copy its input, so the MAE understates the difficulty by an unknown amount. This is a property of the feature set, not of synthetic data: it holds on real records too, since a Vienna window carries its own sustain_cc. The correction exists — model_v2's exclude_features=[14] (commit 9c216c0) drops the column from the input projection — but this page's checkpoint predates it. Read the pedal number as diagnostic only.
  • No movementMap in the emitted document. Pedal is predicted per note as a state; turning states back into movement instructions is the v1.1 reconstruction pass (SYSTEM.md §4). Ornaments and imprecision are likewise out of the v1.0 vocabulary. Where a sustain-CC number is reported it therefore scores a document with no pedal in it — it is the no-pedal null, not a pedal prediction.
  • The articulationMap's values are the heads' raw regression outputs — unrounded floats, where the canonical form is 2 decimals for relativeDuration and an integer for absoluteVelocityChange (CANONICAL A2/A3). They are written as predicted because they are what was rendered and scored; a canonicalisation pass belongs in the export path.
  • Single seed, single checkpoint (runs/v41-asyn-h100/ckpt.pt, epoch 95, 4,282,791 parameters, 16 features, heads on), trained purely on synthetic renderings. One record is an illustration, never evidence — the evidence is the 1000-piece validation and the 220-window Vienna probe in ml/LOG.md.
