Honest caveats

Single seeds — the heads' render/boundary trade vs e96 is not yet attributable. The pedal head's near-perfect state MAE is contaminated (its target leaks into input feature 14) — a v1.0 design correction, already specified. On real data the articulation head over-fires (~135/177 notes): real playing deviates everywhere, unlike canonical synthetic data — thresholding and era priors are the v1.0 answer.
